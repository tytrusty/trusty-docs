TrustySim¶

TrustySim is a simulator you can trust! Solids, cloth, rods, rigid bodies, fluids, you name it: just add it to the scene and it just works. You set up the scene and assign materials; everything is fully coupled, and every solve converges to the accuracy you ask for.

It handles high-resolution multiphysics with frictional contact and coupling between every phenomenon. Applications include finite element analysis, robotics in mixed soft and rigid worlds, and biomechanics, with muscle-driven bodies and soft tissue.

Fully coupled simulation with a T composed of tetrahedra, an r of jointed affine bodies, a u of an aluminium shell, an s of elastic MPM particles, a t of hexahedra and a y of an embedded solid in its voxel grid, all squeezed together by elastic rods. See the code →

Try it¶

Install (pre-release builds are on TestPyPI; see Install), then run a cantilever beam sagging under gravity and look at it in the polyscope viewer:

uv pip install numpy polyscope
uv pip install --no-deps --index-url https://test.pypi.org/simple/ trusty-sim

import polyscope as ps
import trusty

mesh = trusty.make_beam_hex_mesh(size=(1.0, 0.1, 0.1), res=(20, 2, 2))
material = trusty.StableNeoHookean(youngs_modulus=1e6, poisson_ratio=0.3)

world = trusty.World(timestep=1.0 / 60.0)
beam = trusty.fem.add_hex_solid(world, mesh, material, density=1000.0)
trusty.fem.pin_face(world, beam, axis=0, coord=0.0)  # clamp the x = 0 end

for _ in range(60):  # one second
    world.step()

ps.init()
ps.set_up_dir("z_up")
sagged = trusty.fem.read_mesh(world, beam)
ps.register_volume_mesh("beam", sagged.vertices, hexes=sagged.hexes)
ps.show()

Save it as quickstart.py and run it; the viewer opens on the sagged beam:

python quickstart.py

Modules¶

  • Solids

    Hex and tet meshes, linear and quadratic elements, hyperelastic materials.

  • Affine bodies

    Near-rigid bodies, joints, actuators and line muscles.

  • Embedded solids

    Voxelized solids whose surface follows a fine embedded mesh.

  • Shells

    Thin sheets and cloth with membrane and bending models.

  • Rods

    Elastic rods with twist, and rod muscles.

  • MPM

    Particle-based materials such as fluids and granular media.

  • Subspace bodies

    Reduced-order bodies built from a precomputed basis.

  • Contact

    IPC contact, planes and walls, friction, per-body exclusions.

  • Boundary conditions

    Pins, moving targets, attachments and surface loads.
