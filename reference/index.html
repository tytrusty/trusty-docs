read_tet_msh ¶

read_tet_msh(path: str) -> TetMesh

Read a Gmsh .msh file (format 2.2) and return the contained tet mesh. Only 4-node tetrahedra are extracted; orientation is fixed to det([X1-X0|X2-X0|X3-X0]) > 0.

set_max_threads ¶

set_max_threads(num_threads: int) -> None

Cap the worker-thread count for this process. Unset by default, so a lone simulation uses every core. Set 1 when running N independent simulations in parallel (one per process, or one per thread since step() releases the GIL): their internal parallelism otherwise oversubscribes the machine and the pool loses most of what it gained. Takes effect on the next parallel region, so it can be raised or lowered at any time.

add_floor_plane ¶

add_floor_plane(
    world, z: float = 0.0, *, friction_mu: float = 0.0
)

Attach a horizontal floor plane (origin=(0,0,z), normal=(0,0,1)) to world as a contact.ContactPlane component. Returns the new entity (an int). friction_mu is the floor's Coulomb coefficient; 0 (the default) is a frictionless floor. Requires a build with contact enabled (contact.add_plane is only registered then).
